3这一版之前修过的关键问题

  • 「活动：⚠️ 有积分可领（立即领取）」假阳性：改按真实可领积分判定，不再拿服务端静态按钮文案当依据。
  • cron 每天 09:00 不执行：根因是日志文件被 root 创建成 644，ubuntu 的 >> 重定向在启动 Python 前就失败。现改为可写性探测 + 降级日志文件。
  • 单飞锁：看板「立即执行一次」与定时任务并发时只跑一个，避免重复领取。
  • 旅行奖励：到达后先领取再派遣，派出去不会丢积分。
