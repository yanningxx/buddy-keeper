BuddyKeeper · 每日自动值守

WorkBuddy 签到 / 猫猫旅行 / 积分余额 / 成长计划，每天 09:00 无人值守跑一次，结果推送到企业微信。
v1.2.8 cron 每天 09:00 Python 3 · 零第三方依赖（除 paramiko 部署用）
本页只做发布说明，不承载任何账号数据。真实运行状态在本人的值守服务器上，需访问令牌才能查看。

1本次发布内容

  • 修复「活动：⚠️ 有积分可领（立即领取）」的假阳性：改按真实可领积分判定，不再拿服务端静态按钮文案当依据。
  • claim_button_text 降级为纯文案字段，明确注释「不代表可领」。
  • 新增 claimable_credit()：签到看 active && !today_checked_in，任务看进度达成且 accept_status != claimed。
  • 部署脚本移除全部内置凭据，改为环境变量或本地未入库文件提供。

2这一版之前修过的关键问题

  • cron 每天 09:00 不执行：根因是日志文件被 root 创建成 644，ubuntu 的 >> 重定向在启动 Python 前就失败。现改为可写性探测 + 降级日志文件。
  • 单飞锁：看板「立即执行一次」与定时任务并发时只跑一个，避免重复领取。
  • 旅行奖励：到达后先领取再派遣，派出去不会丢积分。
